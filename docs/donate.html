Support WA Desktop

WA Desktop is free and will stay free. If it saves you time every day, a small donation helps keep it maintained.

Donations go through PayPal. Any amount is appreciated.

Donate with PayPal

Opens paypal.me/pahrulirfan

What donations pay for

  • Time to fix bugs, answer issues and keep up when WhatsApp Web changes.
  • Testing on real Windows and macOS machines, not only in CI.
  • One day, perhaps, code-signing certificates so Windows and macOS stop warning about the download.
Donations do not unlock anything. Every feature is available to everyone, with or without a donation. There is no paid version and no account.

Other ways to help

  • Give the project a star on GitHub, so others find it.
  • Report bugs, especially from Windows and macOS: the maintainer develops on Linux. Open an issue and say what works and what does not.
  • Tell friends, colleagues and students who still keep WhatsApp in a browser tab.
  • Improve the code or the documentation; see the contributing guide.

Thank you!
