About WA Desktop

A small, free desktop client for WhatsApp Web on Linux, Windows and macOS, made for people who want WhatsApp in its own window instead of a browser tab.

Who makes it

PI

Pahrul Irfan
Lecturer and researcher in Informatics, Faculty of Engineering, Universitas Mataram (Unram), Lombok, Indonesia.

WA Desktop started because WhatsApp offers no desktop app for Linux. Pahrul Irfan built it for daily use, then shared it with the Linux community, and it now runs on Windows and macOS as well.

Written with the help of Claude

Most of the code, the tests and this documentation were written with the help of Claude, an AI assistant made by Anthropic (the Opus model), working in Claude Code. Pahrul Irfan decides which features to build, reviews every change and tries it on real machines. Automated tests run on GitHub for Linux, Windows and macOS on every change, and every release package is started once in CI before it is published.
